1. Oracle Payroll Basics (24 answers)
What is Oracle HCM Payroll?
Complete global payroll management engine integrated with HCM Cloud; handles calculations, taxation, compliance, payments, reporting.
What are the key features of Oracle Payroll Cloud?
Legislative updates, retroactive processing, Fast Formulas, balance dimensions, cost allocation, payslip, BI publisher, off-cycle, parallel processing.
What are the main payroll components in Oracle HCM?
Payroll definitions, elements, balances, Payroll Relationship, LDG, PSU, calendars, fast formulas, payment methods, costing.
Explain the payroll processing lifecycle.
Pre-payroll → Payroll Run → Prepayment → Costing → Payment Distribution → Archive → GL Transfer → Reporting.
Difference between Payroll Relationship and Work Relationship?
Payroll Relationship: links person to payroll for payments. Work Relationship: employment terms (job, position). Multiple payroll relationships under one work relationship possible.
What is a Payroll Statutory Unit (PSU)?
Legal entity responsible for tax/statutory reporting; groups legal employers under same legislation.
What is a Legislative Data Group (LDG)?
Top-level grouping for a country/legislation, holding statutory rules, currencies, and legal reporting units.
What is Payroll Definition?
Defines processing rules, consolidation group, currency, payment method, and valid calendars for a payroll.
What is Payroll Frequency?
Schedule type: Monthly, Bi-Weekly, Weekly, Semi-Monthly, determines pay period recurrence.
Difference between Monthly and Bi-Weekly payroll?
Monthly: 12 periods/year, Bi-Weekly: 26 periods/year (every 2 weeks). Bi-weekly often used in US/Canada.
What are Payroll Elements?
Reusable components representing earnings (salary, bonus) or deductions (tax, insurance).
Difference between Earnings and Deductions elements?
Earnings increase net pay; Deductions decrease net pay.
What are Standard and Supplemental Earnings?
Standard: recurring regular pay; Supplemental: one-off ad-hoc payments like bonus, commission.
What are Voluntary and Involuntary deductions?
Voluntary: employee elected (charity, retirement extra); Involuntary: legal (garnishment, child support).
What is Element Classification?
Categorizes element behavior (Earnings, Deduction, Employer Contribution, Absence, Information).
What is an Input Value?
User-defined parameter (amount, hours, rate) passed to element for payroll calculation.
What is an Element Eligibility?
Defines which employees receive an element using eligibility profiles or fast formulas.
What are Balance Dimensions?
Time context: period-to-date, quarter-to-date, year-to-date, assignment, tax reporting dimension.
What are Payroll Balances?
Accumulated values from element entries, e.g., Gross Earnings YTD, Total Tax QTD.
What is Cost Allocation?
Distribution of payroll expenses to GL accounts, departments, projects via cost allocation flexfield.
What is Partial Period Accrual?
Pro-rata calculation of benefits / leave accruals for incomplete months worked.
Retroactive Pay setup components?
Retro event triggers, retro elements, formula for recalculation, notification settings.
Proration definition?
Adjusting salary/allowance based on days worked during partial period (hire, termination, mid-month change).
Garnishment element?
Involuntary deduction element with priority, limits and court-ordered amounts.
2. Payroll Setup Questions (full)
Explain end-to-end payroll setup process.
LDG → PSU → Payroll Definition → Calendars → Elements → Element Links → Balance Feeds → Costing → Eligibility Profiles → Payment Methods.
Mandatory setups before payroll processing?
Payroll definition, calendars, elements & entries, payroll relationship, payment methods, costing.
How do you create a Payroll Definition?
Payroll Admin → Payroll Definition → Name, LDG, Consolidation Group, Currency, Period Schedule.
What is a Consolidation Group?
Groups multiple payroll definitions for combined reporting / costing consolidation.
What is a Payment Method?
Bank transfer, cheque, cash. Can be organization default or personal employee override.
Difference between Organization Payment Method and Personal Payment Method?
Organization: company-level default; Personal: employee-specific bank account/ details.
What are Payroll Calendars?
Define period start/end dates, pay date, status, processing deadlines.
What is a Time Definition?
Rules for capturing worked hours, overtime, absence – linked to time card patterns.
What are Payroll Periods?
Specific date ranges within a calendar (e.g., March 1–31).
How do you configure salary basis?
Define salary basis (annual/monthly), link to salary element, via salary basis mapping.
What are Eligibility Profiles?
Dynamic grouping (by department, job, grade) to determine element/payroll eligibility.
What is an Object Group?
Collection of payroll objects (elements, balances, people) for batch maintenance.
What is a Fast Formula database item?
Predefined variable referencing payroll values (e.g., ASG_EARNINGS_RUN, BALANCE_AMOUNT).
What are Value Definitions?
Reusable constants or formula logic for calculations across elements.
Explain Balance Feeds.
Mapping element entry to balance dimension (e.g., Basic Salary → Gross Earnings YTD).
What is Retroactive Pay setup?
Enable retro event triggers, define retro elements, link to calendars, configure notification.
What are Retro Notifications?
Alerts generated when retroactive changes impact prior payroll periods.
Explain Partial Period Accrual?
Pro-rata calculation for allowances/entitlements in partial work month.
What is Proration?
Adjusting earnings/deduction based on worked days vs total calendar days.
What is a Payroll Flow?
Sequence of tasks (calculation, prepayment, costing, GL transfer).
3. Payroll Processing (all steps, reversal, off-cycle, retry)
What are the steps in payroll processing?
Submit payroll → Calculate → Prepayments → Costing → Payment Distribution → Archive → Transfer to GL.
Explain QuickPay.
On-demand simulator for single employee. Tests changes without full run.
What is a Payroll Run?
Main calculation process generating earnings/deductions and balances.
What is a Prepayment process?
Creates payment records, net pay, and calculates payment distribution.
What is Costing?
Allocation of payroll costs to GL accounts (cost centers, projects).
What is Payment Distribution?
Determines how net pay is delivered per payment method (bank, cheque).
What is Payroll Archive?
Stores finalized payroll results for reporting and audit.
What is Payroll Interface?
Transfer data to/from external systems (GL, third-party payrolls).
What is a Payslip?
Employee earnings & deductions statement, generated from archive.
How do you retry a failed payroll process?
Navigate to Payroll Flow → View errors → correct data → Retry action.
What is Payroll Relationship Action?
Internal record capturing each payroll action for an employee (run, reversal).
What is Payroll Assignment?
Link between employee assignment (work relationship) and payroll.
What are Payroll Run Results?
Generated element entries per employee for a payroll period.
Explain Payroll Reversal.
Reverse completed payroll run (post-payment) to correct errors, keeps audit trail.
What is Rollback in Payroll?
Undo payroll run BEFORE prepayment/payments. Reverts results.
Difference between Retry, Rollback, and Reversal?
Retry: re-run failed step; Rollback: undo before payment; Reversal: full negative transaction after payment.
What is Payroll Validation?
Pre-run validation of eligibility, element entries, costing, absence.
How do you process Off-Cycle Payroll?
Unschedule payment (bonus, termination) using off-cycle payroll definition.
Explain Supplemental Payroll.
One-time additional payments separate from regular payroll.
What are Payroll Messages?
Errors/warnings generated during run. View and resolve errors.
How to process final settlement?
Termination off-cycle payroll including last salary, EOSB, leave encashment.
Duplicated payment recovery?
Recovery element entry or negative earnings in next payroll.
4. Fast Formula (Complete)
What is Fast Formula in Payroll?
Oracle expression language for custom calculations, validations & rules.
What are different Fast Formula types?
Payroll, Compensation, Eligibility, Skip Rule, Validation, Deduction, Absence.
What is Payroll Formula Type?
Formula type used within element calculation → calculate earnings/deductions.
What is Compensation Formula?
Used for salary proposals and compensation recommendations.
Explain Skip Rule formula.
Skips processing specific employees based on condition (e.g., no hours).
What is Iterative Processing?
Repeated processing of elements at different priorities within payroll run.
What are Formula Functions?
Built-in functions: GREATEST, LEAST, TO_DATE, ROUND, CEIL, IF THEN ELSE.
What are Formula Database Items?
Predefined values: ASG_EARNINGS_RUN, BALANCE_VALUE, ENTRY_VALUE.
How do you debug Fast Formula?
SET_FF_TRACE(ON), use log output, quickpay with trace, compile logs.
What are Contexts in Fast Formula?
Input parameters (effective date, payroll period, assignment ID).
Explain formula compilation errors.
Syntax errors (missing THEN, ENDIF) or datatype mismatch; checked on save.
What is CALL_FORMULA?
Call another formula from inside a formula, returns value.
What is DEFAULT FOR statement?
Assign default value to variable if not set in context.
What is WAS DEFAULTED?
Boolean function to check if a variable was defaulted.
Explain working storage area (WSA).
Temporary variable area in formula to hold intermediate results.
How do you write a formula for overtime calculation?
IF hours > standard THEN OT_pay = (hours-std)*rate*1.5 ELSE OT=0.
How do you validate employee eligibility using Fast Formula?
Eligibility formula returns Y/N based on hire_date, job, salary band.
Explain salary calculation formula.
DBI: ASG_SALARY_AMOUNT / frequency factor * proration factor.
How do you handle null values in formulas?
Use NVL() or IF variable IS MISSING THEN default.
Explain Payroll Run Result formula usage.
Read from previous element results for cumulative calculations.

Default Values in elements?

Iterative element processing?

Indirect result processing?

Information elements?

Payroll Costing key concepts?

Earnings minus deductions/taxes net pay summary.
Element Result Register?

Payroll Register versus Payment Register?

Payroll REST APIs?

HDL vs REST APIs?

NACHA file generation?
Standard ACH direct deposit file from prepayment results.
Payroll Security Profiles?
Restrict payroll definitions, LDG, employees by user role.
How to restrict payroll access?

Segregation of duties in Payroll?
Separate payroll processing, approval, and GL transfer roles.
10. Payroll Functional Scenarios
Employee salary changed mid-month. Calculation?
Pro-rated salary: (old salary * days_old) + (new salary * days_new) / total month days.
Retroactive salary increases handling?
Update effective-dated salary element, retro event triggers recalculation for previous periods.
Employee joined in middle of payroll cycle?
Proration of salary based on working days, start date element entry from hire date.
Employee resigned before month-end settlement?
Run termination off-cycle, prorate last month salary, EOSB, leave encashment, airfare.
Unpaid leave deductions?
Unpaid absence element reduces salary proportionally.
Duplicate payment recovery method?
Recovery element entry (negative) or payroll reversal and recalc.
Payroll completed with incorrect balance fix?
Adjust balance via balance adjustment element / retro or reversal.
Bonus for selected employees?
Create supplemental bonus element, assign via eligibility profile or batch element entry.
Multiple assignments payroll processing?
Payroll relationship groups multiple assignments, allocate earnings split or primary assignment.
Troubleshoot missing element entries?
Check element eligibility, effective dates, payroll relationship status, link to payroll.
Payroll costing failed – checks?
Validate cost allocation, KFF structure, suspense account, element override.
Payslip not generated troubleshooting?
Check archive completion, payslip template, person’s assignment status.
Employee payment method missing scenario?
System falls back to organization payment method, else error in prepayment.
Bank transfer file rejected (NACHA)?
Check bank account, file format, ABA routing, payment method setup.
Year-end adjustments process?
Balance adjustments, off-cycle payroll, update tax balances.

🌍 GCC Payroll (All 40+ questions: Basics, Setup, Gratuity)
What is GCC Payroll? GCC
Payroll processing for Gulf countries (UAE, KSA, Qatar, Kuwait, Oman, Bahrain) with EOSB, social insurance, housing/transport allowance, WPS.
Which countries are included? GCC
UAE, Saudi Arabia, Qatar, Kuwait, Oman, Bahrain.
Major payroll components in GCC?
Basic, Housing Allowance, Transport, Overtime, Leave Salary, Airfare, EOSB Gratuity, Social Insurance (GOSI/GPSSA).
What is gratuity in GCC?
Mandatory end-of-service benefit based on years of service and basic salary.
Explain End of Service Benefits (EOSB).
Statutory payment per Labor Law: 21 days per year for first 5 years, 30 days afterwards (capped at 2 years salary).
Housing & Transport allowance?
Common as fixed percentage of basic (20-25% housing, 10-15% transport).
What is leave salary?
Payment for unused annual leave upon termination, based on basic salary.
What is airfare allowance?
Annual ticket allowance to home country per labor law.
Overtime processing in GCC?
Usually basic wage / working hours * 1.25 (normal) or 1.5 (night/holiday).
Statutory deductions in GCC?
Social insurance (GOSI for KSA, GPSSA for UAE), sometimes dependent on nationality.
Explain GOSI?
Saudi social insurance: employee 9.75%, employer 12% (pension + unemployment).
What is GPSSA?
UAE pension for nationals: employee 5%, employer 5.83% of salary (capped).
Explain WPS (Wage Protection System).
UAE electronic salary transfer; employers upload file via banks/MOHRE.
What is labor card requirement?
Work permit required before payroll enrollment for expats.
MOL reporting for KSA?
Qiwa platform for contracts and salary reporting.
Configure gratuity elements?
Create EOSB element, fast formula: service months * days entitlement * daily wage.
Explain EOS accrual setup?
Run monthly accrual element to build liability balance.
Configure leave salary calculation?
Leave encashment element using balance dimension "Leave Accrued" * daily rate.
How do you configure airfare eligibility?
Eligibility condition service > 1 year, annual airfare element.
Explain housing allowance calculations?
% of basic or fixed amount; non-taxable in some GCC.
Configure overtime rules?
Fast formula with day classification (Friday premium, overtime multiplier).
How to configure WPS bank details?
Central bank registration, payment method for WPS format.
Gratuity calculation formula UAE?
If service 1-5 yrs: 21 days basic salary per year; >5 yrs: 30 days per year extra. Capped: 2 years total basic.
Saudi gratuity rules?
Half-month wage per year for first 5 years, full month per year thereafter (based on last basic).
Probation impact on gratuity?
No gratuity if resignation during probation, termination may give partial.
Resignation vs termination gratuity (UAE)?
Resignation <3yrs: no EOS; 3–5yrs: 1/3 of 21 days; >5yrs: full 21 days. Termination: full entitlement.
Final settlement processing?
Off-cycle payroll includes last salary + unused leave + gratuity + airfare - recovery.
Multi-country payroll setup GCC?
Separate LDGs per country, localized elements, different payroll definitions.
Localization Fast Formulas used?
EOSB accrual, GOSI brackets, housing allowance calculation.
GCC Payroll compliance?
WPS, GOSI/GPSSA monthly filing, labor law EOSB, Qatar end-of-service.
