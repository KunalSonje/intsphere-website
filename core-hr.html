1️⃣ Core HR Architecture & Key Concepts
What is Oracle Fusion Core HR?
Foundation module of Oracle HCM Cloud that manages employee life cycle: workforce structures, person records, employment, assignments, positions, and global HR data.
What are the key features of Oracle Core HR?
Centralized employee repository, position management, workforce structures (BU, Division, Department), legislative data groups, person profiles, flexible security, self-service, HR extracts, and automated workflows.
Explain the concept of Enterprise Structures in Oracle HCM.
Legal entities, business units, divisions, and departments that represent the corporate hierarchy. Used for costing, security, and approval routing.
What is a Legislative Data Group (LDG) in Core HR?
Grouping of legal entities under common legislation, determines statutory rules (holidays, employment laws, payroll statutory units).
Difference between Legal Entity, Business Unit, and Department?
Legal Entity: legally registered company; Business Unit: operational unit for transactions; Department: functional unit (HR, Finance).
What is a GRE / PSU in HR context?
Legal Reporting Unit / Payroll Statutory Unit – responsible for statutory reporting and payroll compliance.
Explain Division vs Department.
Division: high-level organizational segment (e.g., North America Sales); Department: lower level unit within division (e.g., Retail Sales).
What is the difference between Person and Contact?
Person: Employee/Applicant/Contingent Worker; Contact: dependent, emergency contact, beneficiary (no employment relationship).
What is a Person Type in Core HR?
Classification: Employee, Contingent Worker, Pending Worker, Person of Interest, Former Employee. Determines available actions.
Explain Person Number generation.
Auto-generated unique identifier per person (via sequence / custom logic). Can be manual or system-assigned.
What is an Assignment?
Link between a person and a job/position with specific dates, department, manager, location, and working hours.
Difference between Worker Assignment and Non-Worker Record?
Worker Assignment: employment contract with salary, manager, payroll; Non-worker: dependents, contacts without payments.
Explain Employment Model in Oracle HR.
Person → Employment Terms (Work Relationship) → One or multiple assignments. Supports multiple assignments per person.
What is a Work Relationship?
Legal employment contract between person and legal employer, can have multiple assignments.
What are common Person Security Profiles?
Defines data access: by department, position hierarchy, location, or person type. Used in roles (HR Specialist, Manager).
2️⃣ Workforce Structures: Jobs, Positions, Grades, Locations
What is a Job in Core HR?
Generic role (e.g., Software Engineer, HR Manager) independent of department; defines required competencies, responsibilities.
What is a Position?
Instance of a job within a specific department (e.g., 'HRBP - Finance Dept'). Can be budgeted and have headcount limits.
Difference between Job and Position?
Job: generic, reusable across org. Position: specific, may be one-to-one with employee. Positions support succession planning.
What is a Position Hierarchy?
Reporting relationship among positions (e.g., CEO → VP → Director). Used in approvals and security.
Explain Job Grade / Pay Grade.
Grade defines salary range, pay scale, and eligibility for benefits. Linked to jobs/positions for compensation benchmarking.
What is a Location in Core HR?
Physical address (office, site) associated with assignments for tax, reporting, and work location rules.
What are Organization Trees?
Hierarchical views of departments or positions (Manager, Matrix) used for reporting and security.
What is a Set ID and Business Unit relationship?
Set ID groups reference data (jobs, grades) across business units; shares common HR data.
How do you create a Job in Fusion?
Manage Jobs → Define job code, name, effective date, and optionally Job Family, Grade, Competencies.
How to configure Position management?
Enable Position Sync feature, define position status (Filled, Vacant), assign job & department, control headcount.
3️⃣ Person Management & Worker Lifecycle
Steps to hire an employee in Oracle Core HR.
Create Person → Specify person type (Employee) → Add employment terms → Add assignment (job, department, manager, grade) → Add salary → Submit approval.
What is a Pending Worker?
Pre-hire record before official start date; captures candidate information, documents, future assignment details.
Explain the difference between Hire, Rehire, and Transfer.
Hire: new employee with new work relationship; Rehire: former employee re-joined; Transfer: assignment change within same legal employer.
What is a Global Transfer?
Transfer that changes legal employer (to different country/legal entity). Triggers new assignment and termination of previous.
How do you process a Promotion?
Update assignment with new job / grade / salary, effective date. Can trigger approval workflow.
What is a Concurrent Assignment?
Employee holds multiple assignments simultaneously (primary and secondary) with different roles, departments, or legal employers.
Explain Termination process in Core HR.
Enter termination date, reason (Resignation, Retirement, Dismissal), final processing date, and final settlement. System ends assignments.
What happens to person record after termination?
Person type changes to Former Employee; assignments end; benefits might end; data remains for reporting.
How to manage Return from Leave?
End absence record, reactivate assignment if required, update work schedule.
What is an Assignment Status?
Indicates current state: Active, Suspended, Terminated, Leave of Absence. Controls payroll and benefits eligibility.
4️⃣ Salary Basis, Grades, Compensation Inputs
What is Salary Basis in HR?
Defines how salary is calculated: Annual, Monthly, Hourly, Daily. Linked to grade and payroll element.
How to create Salary record for an employee?
On assignment → Salary → Add salary basis, amount, currency, frequency and effective date.
What is Salary Range and Grade Ladder?
Minimum, mid, maximum for each grade. Ladder defines progression from one grade to next.
What is a Salary Matrix?
Grid of grades and steps for standardized pay determination.
How do you handle mass salary updates?
Use HCM Data Loader (HDL) or salary worksheet (Spreadsheet) to update multiple employees.
Explain Salary Freeze functionality.
Temporarily block salary changes for certain assignments via eligibility profile or administrative hold.
5️⃣ Absence Management fundamentals (Core HR perspective)
What is Absence Management in Core HR?
Module to define leave types (vacation, sick, unpaid), accrue entitlements, process absence requests, and integrate with payroll.
What is an Absence Plan?
Defines leave type, accrual policy (calendar or service-based), carryover rules, and payment percentage.
Explain Accrual formula in Absence.
Fast formula determines accrual amount per period based on length of service, grade, and hours worked.
Difference between Enrolled and Assigned to Absence Plan?
Assigned: employee eligible based on plan assignment; Enrolled: actively participating after enrollment record created.
How does Absence integrate with Payroll?
Absence entries generate payroll elements (paid leave or unpaid deduction) during payroll run.
What is Leave Encashment?
Payment for unused leave balance upon termination or annual buyback, processed via compensation element.
What is a Validation Formula for Absence?
Fast formula checking if absence request qualifies based on minimum notice, available balance, etc.
6️⃣ HR Security (Roles, Profiles, Data Access)
What are Role Mappings in Core HR?
Assigns enterprise/duty roles to users or LDAP groups (HR Specialist, Line Manager, Employee).
What is Person Security Profile?
Filters person records based on department, position hierarchy, location, or person type for role access.
Difference between Data Role and Job Role.
Job Role: functional duties (HR Manager); Data Role: role with specific data security context (e.g., HR for North America).
How do you restrict manager visibility?
Manager security profile limits to direct and indirect reports using position hierarchy.
What is the HR Specialist role responsible for?
Employee data management, hiring, terminations, transfers, salary changes, and absence administration.
Explain Sensitive Person Data protection.
Person records can be marked sensitive; access is restricted; users need data role to view national ID, salary, etc.
What are Custom Roles in Core HR?
Tailored roles combining specific duties (e.g., Recruiter + HR Analyst).
How to test security assignments?
Use "Run Person Security Profile" or test roles as another user (Proxy access).
7️⃣ Integrations: HDL, HCM Extracts, REST, BI Publisher
What is HDL (HCM Data Loader) in Core HR?
Bulk loading tool for worker data: Hire, assignment, salary, address, phone, contact information via CSV/zip files.
Common HDL business objects for Core HR?
Worker, EmploymentTerms, Assignment, Salary, PersonName, PersonAddress, Phone, ContactRelationship.
What is an HCM Extract?
Configurable extract to produce files for external systems (third-party benefits, reporting, government).
Difference between HDL and Spreadsheet Data Loader?
HDL uses dataloader templates (for complex objects). Spreadsheet loader for simpler data (e.g., department, jobs).
What are HR REST APIs?
Oracle REST endpoints for workers, assignments, contacts, allowing real-time integration with third-party apps.
How to schedule an HCM Extract?
Define extract definition → Schedule via ESS job → Deliver via FTP/Email/BI Publisher.
What is the use of Fast Formula in Core HR?
Used for validation rules, default values (e.g., approver derivation), absence accrual, and custom logic.
What is a Workflow in Core HR?
Approval process for transactions (hire, promotion, termination) using BPM tasks or approval rules.
8️⃣ Core HR Reporting: OTBI, BI Publisher, Dashboards
What is OTBI in HR?
Oracle Transactional Business Intelligence – real-time reporting using subject areas (Worker, Workforce Management).
Common HR subject areas in OTBI?
Worker Assignment Real Time, Person Real Time, Workforce Headcount, Absence Real Time, Employment Terms.
What is a BI Publisher report in HR?
Pixel-perfect reports (payslips, contracts, employee letters) using RTF/PDF/Excel templates.
What is the SFTP delivery for extracts?
Option to deliver HCM extract via secure FTP to external vendors.
How to create an employee headcount report?
OTBI report using Worker Assignment subject area, filter active assignments, group by department.
What is a Dashboard in HCM?
Infolets, charts, and analytics cards: Headcount summary, New Hires, Turnover by period.
9️⃣ Functional Scenarios & Problem Solving
Employee transfers to another department mid-month. How is data affected?
Assignment updated with new department, manager, location. Security reflects new team. Salary remains unless grade changes.
Manager left the company – how to reassign direct reports?
Mass transfer of direct reports using "Manage Direct Reports" or update each assignment’s manager hierarchy.
How to correct an employee's hire date?
Use "Manage Person" → Corrective action → Change start date (needs approval). If payroll impacted, coordinate retro.
Employee was terminated in error. How to reinstate?
Rehire the person with same assignment details, backdated start date, and adjust seniority if needed.
An employee has two concurrent assignments. How are deductions handled?
Primary assignment used for main deductions, secondary for earnings with allocation percentages.
How to handle retroactive promotion (promotion effective prior date)?
Backdate assignment change effective date, system recalculates salary and triggers payroll retro if integrated.
Employee moved from hourly to monthly salary basis.
Update salary basis on assignment, end-date hourly salary, create new monthly salary record from effective date.
National ID was entered incorrectly – how to correct?
Use "Manage Person" → Legislative Information → Edit national identifier with effective date.
How to resolve "Assignment Missing Manager" error?
Update manager on assignment via Manage Employment -> Reporting Manager. Ensure manager has active assignment.
Employee not appearing in OTBI report.
Check effective date filters, assignment status = Active, person type, security profile access, and data refresh status.
🔟 Advanced topics: Workforce Lifecycle, Batch Processing, Localization
What is Workforce Lifecycle Management?
End-to-end process from onboarding to retirement, includes events: hire, promotion, transfer, termination, leave, data changes.
What is the use of HCM Spreadsheet Data Loader?
Enable mass creation/update of jobs, positions, grades, departments, cost centers via Excel.
What are Person Keywords?
User-defined tags on person records for search and reporting (e.g., "High Potential", "Remote Worker").
Explain Legislative Data Group (LDG) role in localization?
Defines country-specific fields (passport, national ID formats, address styles) and employment contract templates.
What are Person Extra Info types?
Flexible custom fields to capture country/industry-specific data (emergency contacts, work permit details).
What is Employment Equity reporting (EEO/OFCCP)?
Legislative requirement; Oracle provides extracts for EEOC, VETS reporting using person diversity attributes.
How to manage mass termination of 50+ employees?
Use "Terminate Workers" flow with spreadsheet upload, specify date and reason, submit for processing.
What is the Person Profile?
360° view of employee data: assignments, salary, absence, competencies, performance, documents.
Difference between Person Real Time vs Assignment Real Time subject areas.
Person: name, contacts, personal details; Assignment: role, department, manager, salary, work location.
How to audit Core HR transactions?
Enable Audit for person and assignment objects; use "View Audit History" or HCM Extract for changes.
What are Approval Rules in Core HR?
Conditions based on transaction type, amount threshold, or org hierarchy that route requests for approval.
Explain Position Budget and Headcount Control.
When position management on, each position has budgeted headcount. Hire fails if position is over budget.
🛠️ Core HR Best Practices & Common Troubleshooting
Best practice for effective dated changes?
Always use future-effective or past-effective with correction scope. Use update mode rather than delete/recreate.
How to avoid duplication in HDL loads?
Use merge option, unique person number, or use start date validation to avoid duplicate person records.
Security best practice for HR data?
Least privilege principle: assign person security profiles, separate transactional vs report roles, encrypt sensitive data.
Performance issues when loading large data?
Use HDL batch split, avoid peak hours, review parallel processing settings for ESS jobs.
How to debug failing HCM Extract?
Run extract in trace mode, check log files, validate parameters and date ranges.
Error: "Person number already exists" – resolution.
Check existing record, update person number sequence, or use manual unique identifier.
